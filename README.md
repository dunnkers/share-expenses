# Share Expenses 🍴💸

Split bills with friends faster and easier using Share Expenses. This next-generation application is built using the very latest technology in the field. Insert meaningful transactions into your group using an expressive user interface and collaborate more efficiently using a real-time task list.

## Technology 🏆
This application uses cutting-edge technology. Frameworks include Ember.js, Google's
Polymer, Firebase and Torii Authentication.
